# EasyLift landing page

A responsive landing page for the EasyLift student MVP. Built with plain HTML and CSS; no dependencies or build step required.

## Preview locally

Open `index.html` in a browser, or run this from the project directory:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Edit

- `index.html`: page content and section structure.
- `styles.css`: colors, typography, and responsive layouts.

## Before sharing for research

- Replace the demo placeholder with the team's captioned video, using a titled iframe or a video element with controls.
- Replace the survey placeholder with the actual survey link or a titled embed.
- Keep prototype and illustrative-data labels visible. This page does not collect responses or emails.
- Check the page on a phone and test the demo and survey links.

External Google Fonts are optional; system fonts are used if unavailable.
